说明
  • 每个窗口持有独立的 WindowApi / LoggerApi 实例，不带 controllerKey 参数的方法只作用于当前窗口。
  • 按 key 操作窗口的方法统一以 ByControllerKey 结尾，key 来自 WindowApi.getKey() 或前端全局 $controllerKey。
  • 只有 null 表示主窗口；空串或未知 key 一律视为"找不到窗口"（getter 返回 null、setter 不生效）。
  • alert / confirm / prompt 已由框架对话框接管，可在 app.yml 中替换实现或换肤。
  • 窗口关闭时框架会销毁该窗口的全部桥接器，本页的子窗口列表与日志会自动同步。
